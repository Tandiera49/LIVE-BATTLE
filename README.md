# LIVE-BATTLE

Android interactive battle game designed for TikTok LIVE.

## Current game

- Vertical 9:16 battle screen
- Player A vs Player B
- HP system
- Combo
- Skill
- Ultimate
- Knockout
- Gift-event integration layer
- GitHub Actions Android build

## Build

The Android build is performed on GitHub Actions.

Termux is used for source editing and Git only.

## TikTok integration

TikTok event integration will be connected through the approved TikTok developer/API pathway available to the application. The game engine is kept separate from the event provider so the battle logic does not depend on an unofficial endpoint.
